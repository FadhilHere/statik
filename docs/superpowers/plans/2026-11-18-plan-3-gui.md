# Statik Plan 3 — Aplikasi Desktop (GUI) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aplikasi `Statik.exe` (egui) dengan alur kerja 1:1 SPSS: Data Editor (Data View / Variable View), bar menu SPSS, dialog prosedur & transform, jendela Output dengan tabel bergaya pivot SPSS + grafik, copy ke Word, buka/simpan `.sav`, impor CSV/XLSX, autosave.

**Architecture:** Crate biner baru `statik-app` (eframe 0.37). State aplikasi (`AppState`: dataset, path, dirty flag, undo stack, daftar output) terpisah dari kode UI, sehingga logika bisa dites tanpa jendela; UI dites dengan `egui_kittest` (headless, AccessKit) termasuk snapshot PNG. Prosedur dipanggil lewat struct opsi `procedures::*Options`; dialog hanya membangun struct itu. Jendela Output adalah viewport kedua (egui multi-viewport).

**Tech Stack:** eframe/egui 0.37, egui_extras 0.37 (tabel virtual), egui_plot 0.38 (grafik), egui_kittest 0.37 (tes UI), rfd 0.18 (dialog file Windows), clipboard-win 5 (HTML/RTF/bitmap ke clipboard), serde/serde_json (simpan output & sesi).

**Spec:** `docs/superpowers/specs/2026-11-18-statik-design.md` (§2 G1–G5, §6.1–6.6, §11). Keputusan & temuan tertunda: `docs/superpowers/plan-1-rulings.md`, `KNOWN_GAPS.md`.

## Global Constraints

- Struktur menu persis SPSS: File, Edit, View, Data, Transform, Analyze, Graphs, Utilities, Extensions, Window, Help. Item yang belum diimplementasikan tetap tampil tetapi nonaktif (abu-abu).
- Tidak ada nama "SPSS", logo, atau ikon IBM di UI; judul jendela "Statik"; ikon aplikasi sendiri.
- Bahasa UI Inggris (label menu, dialog, tabel) seperti SPSS.
- Dialog prosedur: daftar variabel sumber di kiri (ikon tipe/measure + label/nama), tombol panah, kotak target, tombol sub-dialog, baris tombol bawah **OK / Paste / Reset / Cancel / Help**.
- Tidak ada panic dari aksi pengguna; error ditampilkan di dialog pesan.
- Ringan: `Statik.exe` release ≤ 15 MB, terbuka < 1 detik, RAM idle < 80 MB.
- Semua angka output berasal dari `procedures` + `output_model::format_cell` (tidak ada format angka di UI).
- Windows 10/11 x64.

## Review Focus

- **Data besar** (100.000 baris × 50 variabel): Data View tetap mulus (virtual scrolling, hanya baris terlihat yang dirender). → tes di Task 3 (benchmark frame time di kittest).
- **Menutup aplikasi dengan perubahan belum disimpan**: harus ada dialog "Save changes?". → tes di Task 7.
- **Mengedit variabel lalu menjalankan dialog yang sudah terisi**: dialog membangun ulang daftarnya dari dataset terkini (VarId usang tidak dikirim ke prosedur). → tes di Task 5.
- **Copy tabel ke Word**: clipboard berisi format "HTML Format" yang valid (header CF_HTML benar) plus teks tab-separated. → tes di Task 4.
- **Layar DPI tinggi / jendela kecil**: dialog tidak terpotong (bisa di-scroll / ukuran minimum). → snapshot di Task 5.
